**PredictMaint** is an end-to-end Machine Learning web application designed to predict equipment failures before they occur. Powered by an ML model trained on the industry-standard **AI4I 2020 Predictive Maintenance Dataset**, this full-stack solution integrates a Python backend service with a modern interactive React dashboard, all orchestrated cleanly via Docker Compose.

---

## ✨ Key Features

- **🧠 Real-Time ML Predictions:** Evaluates operational sensor telemetry (Rotational Speed, Torque, Temperatures, and Tool Wear) to predict machine failure likelihood and specific failure modes.
- **📊 Interactive Frontend Dashboard:** Built with modern React (`Dashboard.jsx`), allowing engineers and operators to input real-time telemetry, visualize equipment health trends, and receive instant diagnostic alerts.
- **⚡ Fast & Lightweight Backend:** Python REST API service serving the serialized machine learning model (`predict_maint_model.joblib`) with low latency.
- **📦 Fully Dockerized:** Ready for instant production deployment or local development using Docker and Docker Compose.
- **📈 Retrainable Pipeline:** Clean data architecture with dedicated training scripts to easily update or experiment with new ML algorithms.

## 🚀 Getting Started

You can run the application either using **Docker Compose** (recommended for quick setup) or by running the Frontend and Backend manually in a local development environment.

### Option 1: Quick Start with Docker Compose (Recommended)

Ensure you have [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/) installed on your machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/PredictMaint.git
   cd PredictMaint
   ```

2. **Build and launch the containers:**
   ```bash
   docker-compose up --build -d
   ```

3. **Access the Application:**
   - **Frontend Dashboard:** Open [http://localhost:3000](http://localhost:3000) (or the configured frontend port in `docker-compose.yml`)
   - **Backend API Docs:** Open [http://localhost:8000/docs](http://localhost:8000/docs) (if using FastAPI/Swagger)

To stop the running containers:
```bash
docker-compose down
```

---

### Option 2: Manual Local Setup

#### 1. Backend Setup
```bash
cd Backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
*The API server will typically start on `http://localhost:8000`.*

#### 2. Frontend Setup
Open a new terminal window:
```bash
cd Frontend
npm install
npm run dev
```
*The React development server will start on `http://localhost:5173` or `http://localhost:3000`.*

## 🔬 Dataset & ML Pipeline

The model is trained using the **AI4I 2020 Predictive Maintenance Dataset** from the UCI Machine Learning Repository. It consists of synthetic telemetry data representing a milling machine's operating conditions:

| Feature | Description | Unit |
| :--- | :--- | :--- |
| **Type** | Product quality variant (L, M, H) | Categorical |
| **Air Temperature** | Ambient temperature around the machine | Kelvin [K] |
| **Process Temperature** | Temperature generated by the manufacturing process | Kelvin [K] |
| **Rotational Speed** | Speed of the spindle | RPM |
| **Torque** | Torque applied during the process | Nm |
| **Tool Wear** | Time the tool has been in continuous use | Minutes [min] |
| **Target** | Machine Failure (0 = No Failure, 1 = Failure) | Binary |

### Retraining the Model
To retrain the ML model from scratch with custom parameters or new data:
```bash
cd Data
python train_model.py
```
This script will read `ai4i2020.csv`, run data preprocessing, train the classifier, and export the updated model weights to `Backend/predict_maint_model.joblib`.

## 📡 API Endpoints

### `POST /predict`
Submit sensor parameters to evaluate the machine's health status.

**Request Body Example:**
```json
{
  "Type": "M",
  "Air_temperature": 298.1,
  "Process_temperature": 308.6,
  "Rotational_speed": 1551,
  "Torque": 42.8,
  "Tool_wear": 0
}
```

**Response Example:**
```json
{
  "failure_prediction": 0,
  "status": "Optimal / Healthy",
  "confidence_score": 0.984
}
```
